Hint: What's the vulnerability?

This page accepts your input and stores it persistently in the backend database. What happens if you submit raw HTML or JavaScript tags instead of regular text? Consider how the browser treats that output when the page reloads.

Solution: How to exploit it

Vulnerability: Stored Cross-Site Scripting (XSS)

Payload (in Name or Comment): <script>alert('XSS Execution!');</script>

Because the application disables output encoding in vulnerable mode (bypassing the template engine's auto-escaping), the browser interprets your payload as executable JavaScript every time someone views the guestbook.
