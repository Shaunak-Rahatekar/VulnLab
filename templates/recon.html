Reconnaissance & OSINT
CIA Impact: 🔴 Confidentiality OWASP: A05:2021-Security Misconfiguration CVSS: 5.3 (Medium)

Before launching an exploit, penetration testers perform Passive and Active Reconnaissance to discover hidden endpoints, technology stacks, and exposed backup files.

1. Robots.txt Analysis

Web crawlers parse /robots.txt to know which paths to ignore. Attackers inspect it to find hidden directories.

Inspect /robots.txt ↗

2. Sensitive Backup Files

Developers frequently leave temporary .bak, .old, or .env files accessible over HTTP.

Access /config.py.bak ↗

3. Discovered Hidden Route

Paths leaked in robots.txt can lead directly to unprotected administration panels.

Visit Discovered /admin/secret_backup ↗

4. Server Banner Grabbing

Attackers send curl -I or use nmap -sV to extract verbose server version information from HTTP response headers.

curl -I http://127.0.0.1:5000/
