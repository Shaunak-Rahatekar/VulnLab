Hint: What's the vulnerability?

This search feature is vulnerable to a UNION-based SQL Injection. By injecting a UNION SELECT statement into the search query, you can trick the database into returning data from other tables (like the users table) right alongside the normal product results.

Solution: How to exploit it

Goal: Extract user credentials.

Payload: ' UNION SELECT id, username, password FROM users --

The backend expects the query to return 3 columns (e.g. id, name, description). By injecting the payload above, we close the original string and force the database to append the id, username, and plain password from the users table into this very same table structure.
