Hint: What's the vulnerability?

Notice how the exact search term you submit in the URL (the ?query=... parameter) is instantly echoed back onto the page in the heading. What happens if that search term isn't just text, but instead contains an HTML tag or a JavaScript payload?

Solution: How to exploit it

Vulnerability: Reflected Cross-Site Scripting (XSS)

Payload: <img src="x" onerror="alert('Reflected XSS!')">

Unlike Stored XSS, this payload is not saved in the backend database. Instead, it is "reflected" directly off the web server back into the DOM. An attacker would craft a malicious URL containing this payload and send it to a victim. When the victim clicks the link, their browser executes the script.
