Hint: What's the vulnerability?

This form is meant to accept image files (like .jpg or .png) for a profile picture. But what happens if you try to upload an executable script (like a Python .py file or an HTML payload) instead? Does the server securely validate the file extension or its contents before saving it to the disk?

Solution: How to exploit it

Vulnerability: Insecure File Upload

Exploitation: In Vulnerable mode, the backend saves any file you upload directly to an accessible uploads/ directory without checking the extension. An attacker could upload a malicious script (e.g., shell.py) or a defacement page (e.g., hacked.html) and then navigate directly to its URL (like /uploads/shell.py) to execute arbitrary code or hijack the web application, leading to a complete server compromise.
