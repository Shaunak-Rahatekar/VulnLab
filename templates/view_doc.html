Hint: What is Directory Traversal?

The backend application takes the ?file=... URL parameter and passes it directly to the filesystem loader. Can you step out of the current docs/ directory using relative path dots (../) to access sensitive files in the application root?

Solution: How to exploit & payload

Vulnerability: Local File Inclusion & Path Traversal (CWE-22)

Exploit Payloads to Try:

  • ../config.py — Leaks application configuration and toggles!
  • ../app.py — Extracts application source code and secret keys!
  • ../detections.log — Leaks administrative detection logs!

Remediation: Use werkzeug.utils.safe_join() and restrict inputs strictly to an allowed whitelist of filenames.
